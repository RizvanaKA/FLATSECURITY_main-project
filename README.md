# FLATSECURITY_main-project

**Project Overview**

The AI-Based Flat Security System is a smart web-based application developed to improve security in residential apartments using Artificial Intelligence technology.

With the rapid increase in apartment living, security challenges such as unauthorized entry, visitor mismanagement, and delayed emergency response have become common. Traditional systems mainly rely on manual monitoring through security guards and CCTV cameras, which may not always be efficient.

This project focuses on developing the web platform of the system to digitally manage apartment security operations in a simple and organized way.

**Objective**

The main objective of this project is to:

1.Improve apartment security using AI technology

2.Reduce manual effort in visitor management

3.Provide faster alert and response mechanisms

4.Maintain digital records of residents and visitors

5.Create a centralized web platform for security management

**Features Implemented (Web Side)**

1️⃣ Resident Management

* Add and manage authorized residents

* Store resident details in database

* View registered residents list

2️⃣ Face Recognition Integration (Concept/Backend Connected)

* Compare captured face images with stored resident data

* Identify authorized and unauthorized persons

3️⃣ Visitor Management

* Store visitor entry and exit details

* Maintain digital visitor records

* Track visitor history

4️⃣ QR Code-Based Entry System

* Residents can generate time-limited QR codes for guests

* Secure and easy guest verification

* Track QR-based entries

5️⃣ Alert & Notification System

* Alert flat owners when unknown persons are detected

* Notify security staff

* Emergency alert feature

6️⃣ Complaint Registration

* Residents can register complaints through the web platform

* Digital tracking of complaints
